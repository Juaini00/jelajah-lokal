# P0 implementation contract

The supplied PRD (docs/PRD.md) and IMPLEMENTATION_PROMPT.md are binding. Product copy is Indonesian; engineering documentation is English. Coordinator owns root configuration, dependency manifests/lockfiles, CI, integration and verification. Backend worker exclusively owns API models, migrations, schemas, content/auth/media services, routes and bootstrap. Editorial implementation uses backend services, never a parallel authorization/database layer.

## Transport

API origin local: http://127.0.0.1:8000. Public web: http://127.0.0.1:4321. Admin production served at /admin/ by FastAPI, Vite base /admin/ (client-side routes fall back to index.html; hashed /admin/assets/* cache immutable, shell no-cache). REST JSON uses camelCase properties. UUID documentId identifiers are stable. All timestamps ISO UTC. Unknown request properties rejected. Errors: {error:{code:string,message:string,requestId:string,retryable:boolean,fields?:{field:string,message:string}[]}}. `fields` lists actionable per-field issues with dotted body paths (e.g. `title`, `sourceLinks.0.url`, `body.3.image.alt`): request validation failures (INVALID_REQUEST), SLUG_CONFLICT/PUBLISHED_SLUG_IMMUTABLE (`slug`), and PUBLISH_VALIDATION_FAILED (every unmet publish requirement, in editor order). Public query validation 400; invalid mutation 422. PRD section 14 error codes/statuses preserved. Responses Cache-Control: no-store except versioned assets.

## Body schema version 1

Body is Block[]. Inline is {type:'text',text:string,bold?:boolean,italic?:boolean} or {type:'link',url:string,children:TextInline[]}. Blocks: {type:'paragraph',children:Inline[]}, {type:'heading',level:2|3,children:Inline[]}, {type:'quote',children:Inline[]}, {type:'list',ordered:boolean,items:Inline[][]}, {type:'image',mediaDocumentId:string,alt:string,caption?:string}. No raw HTML. Only http/https links without credentials; no executable markup. Image resolves an existing media record; public detail image blocks include a safe cover-shaped media property for rendering. Body text max 20,000 code points; publication >=150 meaningful words. AI >=100 words, 7,000-character precheck and official <=2,000 full-input token count.

## Persistent AI guarantees

Official google-genai SDK, verified env model; no SDK or application generation retries. AI disabled still allows manual CMS. Persistent EditorialRequest unique(principal,key), DailyQuota unique(provider,UTC date), GlobalLease singleton, ValidatedCache keyed normalized complete input/model/language/prompt/schema. Short DB transactions; none held during provider HTTP. Lease acquire and quota reserve atomically, commit running before provider call; ownership/fencing prevents old worker releasing new lease. Quota remains consumed after possible provider call. Cache hit requires fresh permissions and caller-owned request. Crashed/expired same-key request never auto-replays. Invalid/truncated/unsafe output rejected with no repair call. Actual token counting includes instruction/schema. Max output500 under verified model semantics, provider timeout30s, lease60s, TTL7days.

## MCP

Official Python SDK protected Streamable HTTP /mcp. Every protocol request, including initialization/discovery, requires X-MCP-API-Key with constant-time comparison. Five allowed tools: list_drafts, read_draft, generate_metadata, apply_metadata, read_usage. Tools call shared permission-aware services as a fixed server-configured principal. No publish/unpublish/delete/environment/SQL/file tools. No caller-controlled principal or role.
