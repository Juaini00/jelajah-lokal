Editorial Assistant · Error states

Pesan menyebut penyebab, status draft, dan tindakan berikutnya. Tidak ada retry otomatis, overwrite konflik, atau publish tersembunyi.

G / P0 · data contoh

01 / Artikel terlalu panjang

Artikel terlalu panjang

Input melebihi batas bantuan AI. Pendekkan artikel untuk proses AI atau isi metadata secara manual. Draft tidak berubah.

INPUT_TOO_LONG

02 / Kuota hari ini habis

Kuota hari ini habis

20 dari 20 proses telah digunakan (UTC). Reset 8 Oktober 2026, 00.00 UTC (contoh). Anda tetap dapat mengisi metadata dan publish manual.

DAILY_QUOTA_EXCEEDED

03 / Gemini membatasi permintaan

Gemini membatasi permintaan

Batas provider berbeda dari kuota aplikasi. Coba lagi nanti secara manual; tidak ada perpindahan ke paket berbayar.

PROVIDER_RATE_LIMITED

04 / Proses melewati batas waktu

Proses melewati batas waktu

Tidak ada hasil yang diterapkan. Draft tetap utuh. Mencoba kembali adalah tindakan baru dan dapat memakai kuota.

AI_TIMEOUT

05 / Akses tidak diizinkan

Akses tidak diizinkan

Anda tidak memiliki izin plugin atau hak untuk membaca dan mengubah draft ini. Tidak ada proses AI atau apply yang dijalankan.

FORBIDDEN

06 / Draft berubah sejak usulan dibuat

Draft berubah sejak usulan dibuat

Metadata tidak disimpan agar perubahan terbaru tidak tertimpa. Muat ulang draft, lalu tinjau usulan kembali.

ARTICLE_CHANGED

07 / Bantuan AI belum siap

Bantuan AI belum siap

Konfigurasi Gemini belum tersedia atau AI dinonaktifkan. Hubungi administrator; penulisan dan penerbitan manual tetap tersedia.

AI_NOT_CONFIGURED

08 / Ada proses yang sedang berjalan

Ada proses yang sedang berjalan

Satu generation sedang aktif. Tunggu proses tersebut selesai sebelum mencoba lagi; tidak ada antrean atau retry otomatis.

AI_BUSY

09 / Usulan tidak dapat digunakan

Usulan tidak dapat digunakan

Format atau batas metadata dari Gemini tidak valid. Tidak ada perubahan pada draft. Isi manual atau coba kembali secara sadar.

INVALID_AI_OUTPUT

10 / Penggunaan belum dapat diperiksa

Penggunaan belum dapat diperiksa

Penyimpanan kuota tidak tersedia. Gemini tidak dipanggil agar batas pemakaian tetap aman. Anda dapat mengedit secara manual.

QUOTA_STORE_UNAVAILABLE

11 / Gemini belum dapat merespons

Gemini belum dapat merespons

Provider mengalami kendala. Tidak ada metadata yang diterapkan; gunakan cara manual atau coba kembali nanti.

AI_PROVIDER_ERROR

12 / Sesi admin berakhir

Sesi admin berakhir

Masuk kembali untuk mengakses draft dan menggunakan Editorial Assistant. Tidak ada perubahan yang diterapkan.

AUTH_REQUIRED
Seluruh error menjaga draft utuh. Konfigurasi dan secrets tidak pernah ditampilkan; editor tetap bisa memakai workflow manual sesuai izin.
